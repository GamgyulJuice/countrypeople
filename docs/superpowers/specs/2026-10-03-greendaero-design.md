# 시골로 포털 개편

목표: countrypeople의 기존 기능을 보존하면서 greendaero.go.kr의 데스크톱·모바일 구성에 가까운 귀농귀촌 포털을 제공한다.

기준: 1440px 콘텐츠, 50px 유틸리티 바와 80px 메뉴, 왼쪽 490px 배너와 오른쪽 2×2 정보 카드, 주요서비스 아이콘, 체험·교육·소식·지역 이야기 순서. Pretendard, 흰 배경, #22a478 녹색, #d1dbf1 테두리, 20px 카드 모서리. 시골로 브랜드를 유지한다.

공개 메인은 로그인 없이 탐색한다. 기존 개인 정책·로드맵·교육 이력·브리핑·프로필은 기존 인증과 데이터 계층을 그대로 사용한다. 공공 프로그램은 공식 링크로 안내하고 모집 상태·날짜를 임의로 만들지 않는다. 예시 정책은 기존 데모 표기를 보존한다. 정부 운영 사이트라고 표시하지 않는다.

구현: src/portal의 독립 포털 화면·헤더·스타일·해시 탐색. 기존 App은 initialPage/onPortalHome/initialSignup만 받아 개인 기능을 표시한다. Supabase 데이터·RLS·인증 API·스키마는 변경하지 않는다. #my/<page>로 개인 화면 진입, #login/#signup으로 인증 흐름. 기존 ?onboarding=1을 지원한다.

검증: 기존 단위 테스트와 프로덕션 빌드, 데스크톱/모바일 실제 브라우저에서 첫 화면·검색·메뉴·슬라이더·개인 화면 진입·온보딩·폼 확인. 390/768/1440 너비에서 가로 넘침 검사. 변경 코드를 별도 브랜치와 PR로 제공한다.
